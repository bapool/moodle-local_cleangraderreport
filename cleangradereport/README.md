# Clean Grade Report

A Moodle local plugin that provides teachers with a clean, print-friendly grade report for parent conferences.

## Features

- Adds a "Print Clean Report" button to the user grade report
- Displays grades in a simplified, easy-to-read format
- Shows grade items with their weights, percentages, and letter grades
- Organized by grade categories
- Highlights course totals
- Print-optimized layout with no unnecessary interface elements

## Requirements

- Moodle 4.3 or higher
- PHP 8.1 or higher

## Installation

1. Download the plugin
2. Extract to `local/cleangradereport` in your Moodle installation
3. Visit Site Administration > Notifications to complete the installation

## Usage

1. Navigate to a course
2. Go to Grades > User report
3. Click the "Print Clean Report" button
4. A new window will open with a clean, printable grade report
5. Use your browser's print function to print or save as PDF
